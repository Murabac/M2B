# M2B Social kit (low volume)

Hard cap: **~5–7 posts/week total** across platforms — one weekly “kernel,” then reshape.

## Platforms

| Platform | Cadence | Tool |
|---|---|---|
| LinkedIn | 2 / week | Native scheduler |
| Instagram | 2 / week (1 feed + Story/Reel when easy) | Meta Business Suite |
| Facebook | 1 / week (often a reshare) | Meta Business Suite |
| X | 1–2 short posts / week | Native schedule |
| TikTok | 0–1 / week only if a Reel already exists | Upload when ready |

## Weekly rhythm

- **Mon** — LinkedIn case insight  
- **Wed** — Instagram visual (+ Story)  
- **Thu** — Facebook reshare of Mon or Wed  
- **Fri** — X shipping note  
- **Sat (optional)** — TikTok / Reel if video exists
